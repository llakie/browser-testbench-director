# Browser Testbench Director 0.1.0

Version 0.1.0 is the first public release of the visual workflow editor and video renderer for Browser Testbench.

## Workflows and projects

Director projects are portable, versioned `.btd.json` files. A graph connects file inputs, browser capabilities, one
website root, JavaScript, browser actions, waits, and visual layers. Project-owned preparation modules can transform
inputs without adding production-specific behavior to the Director runtime.

## Preview and recording

Workflows run in local responsive previews or Browser Testbench targets. Playing a node reconstructs its predecessors
before running the selected node; recording executes the complete graph. CSS viewport dimensions and video output
dimensions are independent, and selected waits can be removed from the final MP4.

## CLI and MCP

The npm package includes the production UI, Director server, CLI, and stdio MCP server. Browser Testbench is installed
as a runtime dependency. Video export requires `ffmpeg` and `ffprobe` on `PATH`.
