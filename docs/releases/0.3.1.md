# Browser Testbench Director 0.3.1

This patch corrects two issues in the 0.3.0 editor and preview runtime. Automatic graph routes now remain orthogonal when they attach to offset node ports, and the website proxy removes the TypeScript module marker before injecting the Director bridge into a proxied page. This preserves `globalThis.__directorWebsitePathname` for website previews such as Binderium.

The README and project-format reference now explain that a globally installed Director provides only the CLI. Projects and their preparation modules remain relative to the workspace from which Director is started.

## Verification

The release candidate passed the full lint, formatting, typecheck, unit-test, production-build, package, and browser release gates.
