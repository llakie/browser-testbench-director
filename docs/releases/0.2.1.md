# Browser Testbench Director 0.2.1

This patch fixes an intermittent recording start failure in Safari on macOS. Director now waits for audio playback to become ready after the browser's audio-unlock click instead of checking immediately.

No project-format or Browser Testbench version change is required.

## Verification

The release gate covers lint, formatting, type checking, unit tests, build, package verification, and browser UI, input-persistence, remote-preview, and recording checks. A macOS Safari recording also produced a 1080 × 1920 MP4 with audio.
