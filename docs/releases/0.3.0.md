# Browser Testbench Director 0.3.0

This release introduces the reusable property-editor architecture and the first specialized authoring nodes. Text layers can be composed from readable line-based settings and generate maintainable HTML and CSS. Audio nodes support pause, seek, start offsets, fades, and editable volume envelopes. Delay nodes, input nodes, compact node menus, and shared responsive editor controls are included.

The editor UI was split into reusable Vue components, templates, SCSS modules, and shared design tokens. Graph execution states and planned `wait-any` branch termination are now represented consistently: planned branch completion shows a check mark, while the stop state remains reserved for an explicit user cancellation.

This release uses Browser Testbench 0.7.4, which waits for OBS readiness after connecting before starting recording-related requests.

## Verification

The release candidate passed the core lint, typecheck, unit-test, and production-build checks. The full browser release gate should be run on a host with Browser Testbench, the configured browsers/devices, OBS, and FFmpeg available.
