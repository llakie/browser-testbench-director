# Browser Testbench Director 0.3.2

This patch adds a terminal screenshot-output node. It captures the selected Browser Testbench target after the connected workflow has reached the node and downloads a PNG or JPEG with the configured filename. JPEG exports support a quality setting. The node uses the same target selection, record control, and empty-state behavior as the established video-output node.

Director now uses Browser Testbench 0.7.5. Its Safari captures use page pixels instead of the rounded native browser window, and Firefox captures remove the transparent phantom row that could appear at the lower edge.

## Verification

The release candidate passed the full lint, formatting, typecheck, unit-test, production-build, package, and browser release gates. The screenshot capture regression was reproduced against Safari and Firefox before release.
