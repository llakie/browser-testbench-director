# Browser Testbench Director 0.3.4

This release adds reusable workflow variables and makes output-specific playback explicit. Input nodes can define a
variable map; values are available to JavaScript through `director.variables`, in HTML via
`{{ variables.key }}`, and to CSS through normalized `--director-key` custom properties.

When a project has multiple output nodes, global playback now asks which output branch to run. This prevents unrelated
exports from running together.

All editor flyouts now use a shared viewport-level portal. They consistently avoid clipping, flip at viewport edges,
keep their anchored arrow, and use the same compact typography. The mobile project menu uses the same mechanism with a
blurred backdrop.

## Verification

The release candidate passed linting, the complete unit-test suite, the production UI build, and Browser Testbench
checks for global flyouts, MIME-type selection, variable references, and mobile-menu layering.
