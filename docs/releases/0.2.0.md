# Browser Testbench Director 0.2.0

This release brings audio workflows and a single preview/recording runtime to Director. Browser Testbench 0.7.2 or newer owns the capture path; Director executes the project graph and exports the captured video and audio, removing intervals marked for omission.

## Highlights

- Audio input and playback nodes support volume envelopes and parallel branches.
- Playing a node reconstructs its predecessors; video-output nodes record the complete workflow and can be stopped during recording.
- The editor has source formatting, clearer run status, color-matched graph ports, a dedicated favicon, and refined node controls.
- Dragging a graph node keeps it visible and reroutes connections without repositioning other nodes.
- The production dependency audit has no known high-severity findings at release time.

## Requirements

Install OBS and FFmpeg on the Browser Testbench machine and FFmpeg on the Director machine. Configure OBS recording in Browser Testbench before recording from Director. Projects remain local `.btd.json` files; the `projects/` directory is intentionally excluded from the npm package and Git repository.

## Verification

The release gate includes lint, type checking, unit tests, a production build, package verification, and browser UI, input-persistence, remote-preview, and recording checks. The recording check verifies MP4 dimensions, duration, and streams with `ffprobe` and representative frames.
